## 🚀 How to Run the Labs

Each lab is self-contained in its respective folder. To run any lab:

1. Clone the repository:
   `ash
   git clone https://github.com/Yashwanth-Reddy-01/bdf-lab-reports.git
   cd bdf-lab-reports
   `

2. Open the desired lab folder (e.g., lab-01):
   `ash
   cd lab-01
   npm install
   npm start
   `

Refer to the README.md inside each lab's folder for detailed endpoint specifications, output screenshots, and viva questions.
